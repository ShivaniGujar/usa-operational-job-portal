# USA Operational Job Portal

A full-stack operational job management application inspired by
the Operational Job Portal described in the apprenticeship report.

## Project goals
- Manage operational units and departments.
- Plan and assign operational jobs.
- Save drafts and activate finalized plans.
- Track execution status and hindrances.
- Provide reporting and notifications.
- Demonstrate professional software engineering practices.

## Technology stack
- Frontend: React, TypeScript, Vite
- Backend: Java 21, Spring Boot, Maven
- Database: MySQL, Spring Data JPA, Flyway
- Testing: JUnit, Spring Boot Test, frontend testing tools
- Version control: Git and GitHub

## Repository structure
- frontend/: React application
- backend/: Spring Boot application
- database/migrations/: database migration assets
- docs/: project documentation
- .github/workflows/: CI automation
